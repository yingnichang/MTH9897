# MTH9897 Bond Relative Value Assignment

This repository contains the Jupyter notebook for the WRDS corporate bond relative-value homework.

## Files

- `bond_relative_value_assignment.ipynb`: executed notebook with data cleaning, spread curve fitting, rich/cheap analysis, duration-neutral portfolio construction, and performance evaluation.

## Data

The WRDS CSV files are not committed. To rerun the notebook, place the two downloaded CSV files in a local `data/` folder:

- `WRDS_Data-Systematic_Trading-Fall2026-1.csv`
- `WRDS_Data-Systematic_Trading-Fall2026-2.csv`
